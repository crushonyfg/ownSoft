# AI 笔记本

这是一个 Windows 本地应用。正文消息和页边批注可就地编辑、收起和移除；顶部功能区可高亮、加下划线、写批注和新建分支。

## 启动

安装 Node.js 22.13 或更高版本，以及你要使用的官方 Codex CLI 或 Claude Code。双击 `Start AI Notebook.cmd`，也可以在此目录运行以下命令。

```powershell
npm ci
npm start
```

## 在另一台机器继续开发

安装 Git 和上述运行环境，然后克隆项目。

```powershell
git clone https://github.com/crushonyfg/ownSoft.git
cd ownSoft
npm ci
npm test
npm start
```

以后更新代码可在项目目录运行 `git pull`。Windows 下也可以双击仓库中的 `Start AI Notebook.cmd` 启动。

每台机器需要分别登录 Codex 或 Claude Code。笔记数据库、附件和登录配置保存在本机。需要转移 PDF 批注时，将保存的 `.aipdf` 文件一同复制到另一台机器，再从应用中打开。

## 应用与账户

左侧栏底部的「应用与账户」页面集中管理各个模型应用和它们的账户，所有聊天共用：

- 每个应用显示命令行工具是否已安装和版本：GPT 用 Codex CLI，Claude 用 Claude Code。没有单独安装 Codex CLI 时，会自动使用 Codex 桌面版自带的 codex.exe。
- 每个应用可以有多个账户。「本机账户」复用对应 CLI 的本地订阅登录；「＋ 账户」创建独立登录配置，点「登录」在官方窗口完成一次授权。
- 每个账户显示登录状态、套餐和邮箱、在本应用里的回答次数和 token，以及额度：GPT 显示 ChatGPT 订阅的 5 小时和每周额度已用百分比与重置时间；Claude Code 不提供剩余百分比，只显示上次回答时附带的限额状态和重置时间。
- Gemini 通过 Google 的 Antigravity CLI（`agy`）接入（个人 Google 账户已不能用 Gemini CLI）。在普通 PowerShell 里运行 `irm https://antigravity.google/cli/install.ps1 | iex` 安装，再在本页点 Gemini 账户的「登录」，在弹出的窗口里用 Google 账户登录后关闭它。然后在聊天的「本聊天成员」里点「导入全部账户」得到 `gemini1`。Antigravity 只支持本机一个 Google 登录，无界面模式不能发送图片；额度显示 Antigravity 自己的 /usage 报告。

## 群聊成员

正文对话是一个群聊。每位**成员**有名字（如 `gpt1`、`claude1`）、头像、模型、Effort 和可选的**角色设定**，并通过一个账户发言。

- 在提问里输入 `@` 会弹出成员列表，也可以点提问框上方的成员名字插入 `@名字`。`@` 多位成员时按顺序依次回答，后面的成员能看到前面成员本轮的回答。没有 `@` 时，由上一次提问 `@` 的成员接着回答（`@` 了多位时是第一位）；这个聊天里还没 `@` 过，或在「本聊天成员」里点了「设为默认」之后，由默认成员回答。提问框上方会写着这次默认由谁回答。
- 应用里所有提问框都是同一个：主对话、侧边分支、批注追问、PDF 选区和全文对话、分头讨论都可以 `@` 成员、添加附件（也可拖入或 Ctrl+V 粘贴截图），按 Ctrl+Enter 发送。
- 每条回答显示成员的名字和头像。模型收到的历史里，各成员的回答以【成员名】标注。

## 模型会话与上下文

展开聊天底部的「主对话上下文」，可选择要带入的消息、批注和记忆。默认开启「续接模型会话」：GPT 和 Claude 在同一聊天、同一成员下接着上轮底层会话回答，保留模型的原生工具调用记录。编辑旧消息、调整上下文、切换模型或账户时，下一轮自动用当前可见上下文新开底层会话。也可点「按当前上下文重开底层会话」，让下一轮从你选好的上下文开始，再继续续接。关闭开关后，每轮都从当前上下文新开。Gemini 暂按每轮重建上下文工作。不同成员和分支的底层会话互相独立。

批注的完整会话会带入批注、标注的引句与所在段落；批注附带的图片或 PDF 也可以由模型按需读取。PDF 审阅会话会提供原 PDF 和按页抽取的文字路径。
- 点顶部「本聊天成员」管理这个聊天的成员：改名、换头像（点头像切换）、选账户、模型和 Effort、设为默认、移除、「导入全部账户」。成员属于各自的聊天；还没改过成员的聊天使用默认成员表。
- **多身份**：同一个账户可以建多位成员。点成员的「＋ 新身份」会用同一账户和模型再建一位，然后在「角色设定」里写它的系统提示（也有「严格审稿人」「反方辩手」「总结整理」「耐心导师」等常用身份可一键填入），例如让 `审稿人` 专挑漏洞、`反方` 专找反例，再 `@` 它们一起讨论。
- 功能区的「模型」「Effort」和顶部的默认成员都只改当前聊天。
- 从旧版本升级时，原有的每个账户会自动变成一位成员。

## 私聊小窗与并行提问

群聊里可以同时进行好几段对话：

- **并行提问**：某位成员还在回答时，可以直接在群聊提问框里发下一个问题（例如先 `@gemini` 再 `@claude1`）。正在回答的那位会自动转到私聊小窗里继续生成，群聊立刻回答新问题；新问题的上下文只包含之前公开的群聊内容，不包含转走的那条。也可以点正在生成的回答上的「转到小窗」。转走的回答在群聊原位置留一张折叠卡片，显示问题和回答开头（生成中实时更新）、状态和新回答数；点「展开」在群聊里看完整私聊记录，「打开小窗」继续私聊。卡片不进入上下文，删除私聊小窗时卡片一起移除。
- **右侧头像**：每段私聊在屏幕右侧有一个成员头像。转圈表示正在回答，绿色数字表示有几条新回答还没看。点头像打开或收起小窗，点「＋」选成员开新的私聊。
- **从消息开私聊**：每条回答右上角的 ↗ 会开一个和这位成员的私聊小窗，从这条回答接着单独追问。
- **小窗布局**：小窗默认约占屏幕 1/4，开几个会自动平铺；也可以拖标题栏移动、拖边框和四角缩放，拖到屏幕左右边缘贴成半屏、拖到顶部最大化，或用 ⊞ 菜单选左/右半屏、四个 1/4 位置和最大化。双击标题栏在最大化和自动排列之间切换。
- **私有与发布**：私聊里其他成员看不到。聊完点「发布到群聊」，先在编辑框里删改整理，再作为笔记块放进群聊，进入之后所有成员的上下文；「设为私有」会把它撤回。头像菜单里的「让默认成员汇总已发布的私聊」会在群聊提问框里放好汇总问题。

## 主对话上下文

默认情况下，提问会带上这份笔记里之前的全部消息，页边批注不带。展开提问框上方的「主对话上下文」，点「选择消息和批注作为上下文…」：消息和页边批注旁会出现勾选框（消息也可按住 Ctrl/Shift 点选），底部有「全选」「全不选」。点「设为上下文」后，之后的提问只带上选中的消息和批注，以及选择之后的新消息；没选中的消息会变灰，选入的批注标着「在上下文中」。点「改回全部」恢复默认。

关闭「续接模型会话」或调整上下文后，模型从所选消息、批注、公共笔记、附件路径和这次的问题重建上下文。默认续接时，底层模型会话保留自己的工具记录。应用也保存工具的文字结果，并优先把最近的结果带入重建后的上下文；过长的结果可由模型用下述 ownsoft 工具按需回查。对话很长时，可以用「选择消息和批注作为上下文」控制主动带入的部分。

## 模型访问笔记本内容

GPT 和 Claude 会自动连接本机的 `ownsoft` MCP 服务。模型收到当前会话 ID，需要更多背景时可调用 `search_library` 查找相关会话、Markdown 和 PDF 审阅，调用 `read_chat` 分页看消息与批注，再用 `read_message` 分段取一条消息及其已保存的工具结果。`read_markdown`、`read_pdf_review` 和 `read_annotation` 可继续追查文档、PDF 批注与追问子会话。这样局部批注追问不必每轮附上整个原会话；模型可以按需回读。Gemini 暂无此 MCP 接口，仍使用应用构建的上下文。

用户要求保存成果时，模型可调用 `save_markdown` 或 `import_markdown` 创建 Markdown 文档，并指定会话 ID 将它插为笔记块；已有文档可用 `insert_markdown_block` 插入，无须重新发送全文。`add_note_block`、`add_annotation`、`edit_annotation` 可修改笔记和批注。导入本地文件需要绝对路径。MCP 只在本机启动，通过标准输入输出与模型通信，直接使用当前笔记数据库；外部写入会刷新已打开的应用窗口。

聊天消息间点「＋ MD文档」可插入已有 Markdown 作为笔记块。点击卡片可放大进入 Markdown 编辑、预览和追问。编辑普通笔记块或 Markdown 源码时，输入 `/` 和会话或文档标题，可插入内部链接；链接写成普通 Markdown，例如 `[研究记录](ownsoft://md/文档ID)`，点击后会打开对应内容。模型读取笔记文本时也能看到该链接，并按 ID 继续追查。

## 消息转为笔记或批注

每条消息（包括你自己的提问）右上角有两个图标：

- **转为笔记块**：在原位置用笔记块替换这条消息，图片附件变成图片笔记块，原消息从页面和对话历史中移除；原有批注、分支和标记会跟随文字笔记块。
- **转为页边批注**：把消息移出主对话，变成页边批注（作者写明是谁的回答或你的消息），附件随批注保留。点图标后选择挂在哪里：选中任意消息里的一段文字，点浮动工具条或底部的「挂在这里」；或直接点一条消息，挂在它的开头；也可以点「挂在相邻消息」。按 Esc 或「取消」放弃。批注默认不进入上下文，需要时在「主对话上下文」里选入。
- 从消息转来的页边批注有明确的「撤销转批注」按钮，可把原消息放回聊天。旧版批注缺少来源 ID 时，会优先使用唯一的原消息空位；如果位置无法确定，则在所批注的段落旁恢复内容。PDF 全文对话中的消息点「转为批注」后，可在左侧 PDF 选中文字并点「挂选中为批注」；批注与下划线保存在 PDF 审阅中，也会出现在主聊天的 PDF 笔记卡片里。PDF 批注卡片的「撤销转批注」同样能恢复原消息。已有追问的批注需先处理追问，才能撤销转换。

## 模型工具

GPT 可使用 Codex 的内置工具，包括实时网页搜索和命令执行；Claude 可使用 Claude Code 默认的内置工具，包括 WebSearch、WebFetch、文件操作和命令执行。模型按问题决定何时调用工具。查询最新行情时，请在问题中要求核实数据日期和来源；搜索结果不保证是实时交易报价。

Codex 在需要额外命令、文件或网络权限时会在应用内弹出确认窗口。Claude Code 使用其自动权限模式处理工具调用。工具默认在数据文件夹的 `model-work` 中运行；给笔记指定工作文件夹后改在那个文件夹中运行（见下文「聊天的工作文件夹」）。对话历史仍由本应用保存在笔记数据库中。

后续提问会带上此前的问答和工具调用记录。成功调用的文字结果保存在本地（单次最多约 20 万字符，作为异常超大输出的保护），可在折叠的工具记录里展开查看。构建下一轮上下文时，优先带入最近的完整结果；可用空间不足时才缩短，工具结果合计最多约 16 万字符，并为提问、历史、附件和回答留出空间。被排除的消息及其工具结果不会进入主对话上下文。完整的 PDF 不会每轮塞进提示词：应用只抽取一次按页文字并缓存为本地文件，模型可按需重读具体页。扫描页和图表仍可能需要再次查看原 PDF。

## 使用

左侧的「＋ 新主题」建立目录，「＋ 新会话」时可选择所属主题。主题列表可折叠；每个会话旁的三点菜单可在新窗口打开、重命名、移到其他主题或删除，主题的三点菜单可重命名、在其中新建会话或删除主题。新窗口可拖到另一台显示器；每个窗口独立停留在自己的会话，修改会同步刷新到其他窗口。删除主题会把其中的会话移到「未分类」，不会删掉会话内容。正文、批注和分支随各自的会话保存。页边批注顶部的图标可收起、就地编辑（支持预览）、删除、固定为记忆或放大阅读。

分支打开时成为焦点视图，主聊天在下层变暗并露出边角；点「返回主聊天」或按 Esc 收起。长批注在页边显示摘要高度，点 ↗ 放大：左边是完整的对话（图片和 PDF 笔记照常显示），自动滚到批注所在的消息并高亮被批注的句子；右边是批注和追问。中间的分隔条可以左右拖动调整宽度（双击恢复）。点「在正文中定位」回到原文。

普通笔记和 PDF 的每条批注都可以直接展开「追问」。点「新开分支」会在左侧创建一份笔记，带上批注、对应的原文和已完成的追问。

1. 在正文底部向当前模型提问，或在对话中任意位置插入笔记块、图片块。
2. 选中正文里的文字，点「侧边提问」。侧栏会显示送给模型的段落、选入的记忆和当前分支的问答轮数。
3. 从侧边回答中选择要保留的文字，点「选中文字存为批注」。删掉侧边对话后，页边批注仍可点击定位原句。
4. 「从选区建分支」会新建分支，并切到「关系图」选中它，右侧直接是这条分支的会话。也可以把批注固定为记忆，再在侧边对话里按需勾选。

## 关系图

顶部的「关系图」显示当前会话派生出的所有对话：页边批注和它的追问、侧边分支、私聊小窗、会话里的 PDF（它的全文对话和每条批注的追问）。追问本身也是完整会话，在里面再做的批注、分支、私聊会继续挂在下一层。

- 「图」是从左往右展开的结构图，「树」是缩进的大纲；节点右侧的 ▾ / ▸ 可以收起或展开下一层，「全部收起」一键折叠。
- 节点上写着类别、标题、轮数和最后更新时间；还没有追问的批注显示「还没有追问」。
- 点一个节点，右侧就是这段对话的完整会话，可以直接继续提问，图上的轮数会跟着更新。「在原处打开」跳到它所在的位置（放大批注、侧边分支、私聊小窗或 PDF 审阅），「完整会话 ↗」在新窗口打开。
- 点 PDF 节点可以打开它的审阅；点最左边的会话节点回到正文。在一个派生会话的窗口里打开关系图，根节点可以打开来源会话。

## 对话历史和附件

- 主对话中，你的消息在右侧，模型回答在左侧。同一轮回答的多个段落合为一条消息。每条消息右上角的图标可单独收起、编辑或移除。编辑直接在原消息内进行，可在「编辑 / 预览」之间切换；取消「用于主对话」可以保留原文供阅读。下一轮会沿用保存后的主对话历史。
- 笔记块（公共笔记）和对话消息按顺序排在同一条正文里。鼠标移到两条消息之间会出现「＋ 笔记块」「＋ 图片」，可在任意位置插入；也可把 PNG/JPG/WebP 图片拖到消息之间。功能区的「新建笔记块」「插入图片」插到当前选中消息的下方，未选中时插到对话末尾。拖动笔记块左上的把手可把它移到任何两条消息之间。笔记块默认进入后续主对话及侧边对话的上下文；编辑时可取消「用于 AI 上下文」。模型回答右上角的笔记图标会在原位置用笔记块替换这条回答。
- 像 notebook 的单元格一样，点消息空白处即可选中它（左侧出现蓝条）。选中后可用键盘：↑/↓ 或 K/J 移动，B 在下方插入笔记块，A 在上方插入，Enter 编辑，Delete 移除，Esc 取消选中。按住 Ctrl 点击可加选或取消某条，按住 Shift 点击或 Shift+↑/↓ 可连续多选。
- 回答会逐步显示，工具调用以可展开的记录显示，默认收起。每条正文消息可单独「收起」或「展开」。点「多选消息」（或用 Ctrl/Shift 点选）选择提问、回答或笔记后，可以「新建聊天」；所选回答会自动带上对应提问，并复制所选内容上的批注、分支和选入的记忆，原聊天保留。
- 点顶部「✦ 外观」可选择四种聊天背景，并分别设置自己、GPT 和 Claude 的像素头像。头像会随等待、生成回复和工具运行切换动画状态。外观保存在本机，对所有笔记生效。
- 把批注固定为记忆后，可在「主对话上下文」里勾选它。侧边对话沿用选中段落、本分支问答和本分支选入的记忆。
- 正文和侧栏都支持用「＋ 附件」添加文件，也可拖入提问框，或在提问框里按 Ctrl+V 粘贴截图。在正文空白处按 Ctrl+V、或把图片拖进正文，会插入为图片笔记块（插在选中消息下方，未选中时插在末尾）。截图和从其他应用拖来的图片不需要文件路径。支持 PDF、PNG、JPG 和 WebP。每条消息最多 6 个文件，每个文件最多 100 MB。
- 附件不再被压缩成提问里的一段文字，而是把文件在本机的路径告诉模型，模型需要时用自己的读文件工具去读，没有页数或字数上限。每个 PDF 第一次用到时会抽取一份按页标注的文字（存在数据文件夹的 `attachment-text`），和原文件一起给模型：Claude Code 可以直接读 PDF 看图表，其他模型可以读抽好的文字。本次提问里随附的图片和框选截图仍会直接发给模型看（Gemini 的无界面模式收不了图片，会按路径自己打开）。
- 附件随发送的消息保存在本地。PDF 在发送前或发送后点「审阅」可直接进入 PDF 审阅；返回后聊天草稿仍在。其它附件点击名称可以打开。后续提问会引用本对话保留的附件。发送时会把选用的文字和图片传给当前模型。

## 数据管理与备份

点左侧栏底部的「数据管理与备份」可以查看和管理数据。

- **数据位置**：正文、批注、分支、附件、账户配置和备份都在同一个数据文件夹里，默认是 `%USERPROFILE%\.ai-notebook`。点「更改位置…」选一个文件夹（例如 `D:\AI Notebook Data`），数据会复制过去，应用自动重启并从新位置运行；原位置的数据保留不删。所选位置记在 `%USERPROFILE%\.ai-notebook\location.json`。数据不放在 `%APPDATA%`，因为从 Codex、Claude 等商店版桌面应用里启动程序时，Windows 会把它写入 `%APPDATA%` 的内容转到那个应用的私有目录，导致不同启动方式看到不同的笔记。设置环境变量 `AI_NOTEBOOK_DATA_DIR` 可强制使用某个目录。
- **自动备份**：每次启动、关闭和运行中每 6 小时，只要笔记有改动就在数据文件夹的 `backups` 里存一份数据库快照，保留最近 30 份。手动备份、恢复前和迁移前的备份不会自动删除。
- **恢复**：在备份列表中点「恢复」，或「从文件恢复…」选择 `.sqlite` 快照或导出的 `.zip`。恢复前会先把当前数据另存一份，然后应用自动重启。
- **导出完整备份**：生成一个 `.zip`，包含数据库和全部附件，适合拷到别的盘或另一台电脑。
- **附件不会被直接删除**：删除消息后不再使用的附件会移到 `attachments-trash`，恢复旧备份时自动找回。

## 聊天的工作文件夹

每份笔记可以指定一个本地文件夹，就像 Codex 或 Claude Code 打开的项目目录。点正文提问框右下角的「📁 工作文件夹」选择文件夹后，这份笔记的主对话、侧边对话和批注追问都在那里运行，模型可以读取和修改其中的文件。点 ↗ 在资源管理器中打开，点 × 改回默认文件夹（数据文件夹里的 `model-work`）。从所选消息新建的聊天会沿用原笔记的文件夹。

## PDF 审阅

审阅属于 PDF 本身，不属于哪个聊天：一份 PDF 的批注、批注追问、选区问答和全文对话都跟着这份 PDF 走，不管从哪个聊天、笔记或附件打开，看到的都是同一份审阅（按文件内容识别，改名或换位置也认得）。审阅随时自动保存，不需要另存文件。

**打开审阅**

- 聊天里的任何 PDF——PDF 笔记块、消息或批注里的 PDF 附件——右键选「审阅」，或直接点它。也可以右键选「全文对话」「在新窗口审阅」「用默认程序打开」。
- 左侧栏「PDF 审阅」列出所有审阅过的 PDF（显示批注数和对话轮数），点开继续；右键可在新窗口审阅或删除这份审阅。「＋ 打开」可以直接审阅电脑上的 PDF 或 `.aipdf`。
- 审阅页盖在当前页面上，点「关闭审阅」或按 Esc 回到原来的笔记页。

**PDF 笔记**：点「插入图片/PDF」，或把 PDF 拖进正文、在正文空白处 Ctrl+V，PDF 就成为正文里的笔记块，显示页面预览（可翻页）、这份 PDF 审阅里的批注数和最近几条批注。PDF 文件（以路径的形式）和它的批注会进入群聊上下文，群聊里可以直接问成员关于这份 PDF 的问题。

**审阅页**：PDF 页面纵向连续排列，页码随滚动更新。右栏上半部分是批注和选区问答，下半部分是「全文对话」，两者同时显示；PDF 和右栏之间、右栏上下两部分之间的分隔条都可以拖动（双击恢复）。点「在新窗口打开」把这份 PDF 放到单独的窗口，拖到另一块屏幕；之后在聊天里再打开同一份 PDF 会切到那个窗口。

- 选中 PDF 文字后点「新建批注」写批注；点批注标题或正文下划线可相互定位，每条批注都能追问。
- 选中文字后点「问 AI」，或点「框选提问」拖出矩形，就文字或截图提问；对文字选区的有用回答点「存为批注」，会挂在那段文字上，追问记录一起保留。
- 「全文对话」把这份 PDF 和已有批注交给回答的成员（不限页数，成员按需阅读），用来总结、找漏洞或比较章节。回答的成员是当前聊天的成员。

**文件**：审阅过的 PDF 会在数据文件夹的 `reviews` 里留一份副本，所以原文件移走后仍能从侧栏打开。点「导出 .aipdf」可以把 PDF 连同批注和对话带到别处；`.aipdf` 是 ZIP 容器，包含原始 `document.pdf` 和版本化的 `review.json`（原文件的 SHA-256、批注页码、原文引句、归一化页面坐标、追问和全文对话）。打开 `.aipdf` 时，其中的批注和对话会并入这份 PDF 的审阅。

## 每段对话都是完整会话

批注的追问、侧边分支、私聊小窗、PDF 和 Markdown 文档的批注追问与全文对话，都保存为各自的会话，并记得自己从哪里来（哪个会话的哪条批注、哪份 PDF、哪篇文档）。它们仍在原来的地方以紧凑的问答列表显示；点「完整会话 ↗」（私聊小窗标题栏的 ↗）会在新窗口里把这段对话作为完整会话打开，主会话能做的都能做：编辑、收起、高亮和下划线、转笔记块或页边批注、多选、选择上下文、@ 多位成员依次回答。在完整会话里提问时会自动带上来源（PDF 原文和批注、文档全文、批注所在的原文、分支所在的段落），问答也会出现在原来的地方。窗口顶部的提示条可以打开来源会话。这些会话不列在左侧的会话列表里。

不另开窗口也能用完整会话：PDF 审阅和 Markdown 文档侧栏的下半部分就是完整会话，默认是全文对话；点某条批注的「追问」切换到这条批注的会话，点「← 全文对话」切回。放大批注时，右侧批注下方是它的追问会话；放大分支时，整个放大层就是这条分支的会话。私聊小窗标题栏的 ⤢ 在小窗里切换简洁视图和完整会话（⤡ 切回）。嵌在这些地方时，工具栏收成一行，窄的时候可以横向滚动。

从旧版本升级时，原来存在批注、分支、私聊和审阅里的对话会在第一次启动时转为会话，转换前会先自动备份（数据管理里的「迁移前」备份）。

## Markdown 文档

左侧栏「Markdown 文档」点「＋ 打开」选择电脑上的 `.md` 文件（也可以直接把文件拖进窗口），或点「＋ 新建」。文档在聊天上方打开，关闭后回到原来的聊天。

- **预览 / 分栏 / 源码**：预览看排版效果；源码直接修改 Markdown；分栏左边写、右边实时预览，滚动跟随。
- **保存**：边写边自动保存在应用里；「保存到文件」（Ctrl+S）写回原来的 `.md` 文件，「另存为…」（Ctrl+Shift+S）存成新文件。还没写回的改动会在标题旁提示，关闭文档时也会询问。原文件在别处被改过时，再次打开会自动载入新内容（应用里有未写回的改动时保留应用里的版本并提示）。
- **提问和批注**：在预览或源码里选中一段文字，点浮动的「问 AI」/「批注」或工具栏的「问所选」/「批注所选」。选区提问可以 @ 多位成员，有用的回答点「存为批注」挂在这段文字上。批注在预览里以下划线标出，点下划线跳到批注；改动文档时批注跟着移动，被改掉的那段会标成「找不到这段文字」。侧栏下方的「全文对话」把文档原文和已有批注一起发给成员。
- 左侧栏右键文档可以在文件夹中显示，或从列表移除（不删除电脑上的文件）。

## 公式

聊天回答、批注和 Markdown 文档里的公式都用 KaTeX 排版：`\(…\)`、`$…$` 为行内公式，`\[…\]`、`$$…$$` 为独立公式（可以跨多行，单独成段时里面的 `-`、`#`、空行也不会被当成列表或标题）。公式里的 `_`、`*`、`\\` 不会被当成 Markdown 语法。`$` 按 Pandoc 的规则识别，像「$608.45 到 $606.23」这样的金额仍显示为文字；写 `\$` 可强制显示美元符号。代码块和行内代码里的内容不渲染。写错的公式显示原文，不影响其余部分。
